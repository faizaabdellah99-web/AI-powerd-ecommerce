# E-Commerce AI Dashboard

---

| Feature | Tech |
|---|---|
| Demand Forecasting | Prophet (Facebook) / NumPy |
| Smart Pricing | scikit-learn + competitor data |
| AI Product Description | Claude API (Anthropic) |
| AI Image Generator | DALL-E 3 (OpenAI) |

### Customer Dashboard
| Feature | Tech |
|---|---|
| Predictive Re-ordering | Order history analysis |
| Visual Search | CLIP + FAISS vector search |

## Quick Start

### 1. Prerequisites
- Node.js >= 18
- Python >= 3.10
- MongoDB (local or Atlas)

### 2. Clone & install

```bash
git clone <repo>
cd ecommerce-ai-dashboard

# Install Node dependencies (root + server + client)
npm run install:all

# Install Python dependencies
cd ai-services
pip install -r requirements.txt
cd ..
```

### 3. Environment variables

```bash
# Server
cp server/.env.example server/.env
# Edit server/.env — add MongoDB URI, JWT secret, API keys
```

### 4. Run all services (3 terminals)

```bash
# Terminal 1 — MongoDB (if local)
mongod

# Terminal 2 — Node.js server (port 5000)
cd server && npm run dev

# Terminal 3 — Python AI services (port 8001)
cd ai-services && uvicorn main:app --reload --port 8001

# Terminal 4 — React client (port 3000)
cd client && npm start
```

Or use concurrently from root:
```bash
npm run dev
```

### 5. Open the app
- Frontend: http://localhost:3000
- Node API: http://localhost:5000/health
- Python AI: http://localhost:8001/health
- API docs: http://localhost:8001/docs  ← auto-generated by FastAPI

## API Endpoints

### Auth
```
POST /api/auth/register
POST /api/auth/login
GET  /api/auth/me
```

### AI Gateway (Node → Python)
```
POST /api/ai/demand-forecast       → admin/vendor
POST /api/ai/smart-pricing         → admin/vendor
POST /api/ai/generate-description  → admin/vendor
POST /api/ai/generate-image        → admin/vendor
POST /api/ai/reorder-prediction    → customer
POST /api/ai/visual-search         → all (multipart/form-data)
```

### Products & Orders
```
GET  /api/products
POST /api/products
GET  /api/orders/my
POST /api/orders
```
